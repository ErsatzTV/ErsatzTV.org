[Aero](https://aeroplay.tv/) is an IPTV player for macOS, available on the Mac App Store.

### Add Playlist

Add a playlist under **Settings** > **Playlists** > **Add playlist**.
Paste the **M3U** url from ErsatzTV (see [required urls](/docs/clients/#required-urls)) into the playlist's link field.

### EPG

Aero reads the **XMLTV** url from the playlist, so the guide appears without extra setup.
