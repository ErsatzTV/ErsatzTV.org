An image or video graphics layer composited on top of the primary content. Sized and positioned relative to the primary content's frame.

| Property | Type | Default | Since | Description |
|---|---|---|---|---|
| `source` (required) | [`PlayoutItemSource`](#playoutitemsource) |  | 0.0.1 | The source providing the graphics media (typically an image, but any `PlayoutItemSource` is accepted). |
| `stream_index` | `integer` |  | 0.0.1 | Zero-based stream index within the source. If omitted, the server picks the first video stream. |
| `kind` | [`GraphicsLayerKind`](#graphicslayerkind) |  | 0.0.4 | Graphics layer kind. |
| `location` (required) | [`GraphicsLocation`](#graphicslocation) |  | 0.0.1 | Anchor position within the primary content frame. |
| `width_percent` | `number` |  | 0.0.1 | Scale the graphics layer to this percent of the primary content width (0–100). Omit to use its actual size. |
| `horizontal_margin_percent` | `number` |  | 0.0.1 | Horizontal offset from the anchor `location`, as a percent of primary content width (0–100). Omit for 0. |
| `vertical_margin_percent` | `number` |  | 0.0.1 | Vertical offset from the anchor `location`, as a percent of primary content height (0–100). Omit for 0. |
| `opacity_percent` | `number` |  | 0.0.1 | Opacity as a percent (0–100). Omit for fully opaque (100). |
| `within_source_content` | `boolean` |  | 0.0.1 | When true, position margins are measured from the edges of the source content rather than the padded output frame, so letterbox/pillarbox bars push the graphics layer inward and keep it inside the visible content. When false, margins are relative to the full padded frame, so a 0% margin can land inside the bars. Has no effect when the primary content fills the output (crop/stretch). Omit for false. |
| `timing` | [`GraphicsTiming`](#graphicstiming) |  | 0.0.1 | Visibility schedule for the graphics layer. Omit for an always-on layer. |
