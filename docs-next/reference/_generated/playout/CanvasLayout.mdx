Where the canvas is placed in the output frame. `mode` selects the variant.

**`mode: "full_frame"`**

The canvas has the output size and is placed at (0,0). A canvas with a different size (stale playout metadata) is stretched to the output size.

**`mode: "region"`**

The canvas covers part of the output. It is placed at `origin` at its own size, without scaling. `origin` is in output pixels and does not change with the output resolution. Parts outside the output are clipped. A canvas fully outside the output is skipped.
