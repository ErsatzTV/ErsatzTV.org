Settings for one channel: where its playout is, which ffmpeg to use, and the output format.
A relative path in any of these settings is relative to the file that sets it.

| Property | Type | Default | Since | Description |
|---|---|---|---|---|
| `fallback` | [`FallbackConfig`](#fallbackconfig) | `{"show_error":false}` | 0.1.0 | What plays when nothing is scheduled or an item fails. |
| `ffmpeg` (required) | [`FfmpegConfig`](#ffmpegconfig) |  | 0.1.0 | ffmpeg and ffprobe settings. |
| `normalization` (required) | [`NormalizationConfig`](#normalizationconfig) |  | 0.1.0 | Output format for audio, video and subtitles. |
| `playout` (required) | [`PlayoutConfig`](#playoutconfig) |  | 0.1.0 | Where to find the channel's playout files. |
| `version` | `string` |  | 0.1.0 | Schema version URI, e.g. "https://ersatztv.org/channel/version/0.1.0". Missing means 0.0.0. |
