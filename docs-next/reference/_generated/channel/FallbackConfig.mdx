Controls the content that replaces scheduled content when there is nothing to play
(a gap in the playout) or when the scheduled item fails

| Property | Type | Default | Since | Description |
|---|---|---|---|---|
| `duration_seconds` | `integer` |  | 0.1.2 (unreleased) | Fallback length in seconds when the fallback has no end time, e.g. after a failed dynamic source. Default 60. Raised to the source's `retry_budget_ms` if shorter. |
| `show_error` | `boolean` | `false` | 0.1.0 | Burn the reason for the fallback into the fallback video; this is always burned, regardless of the normalization subtitle mode |
