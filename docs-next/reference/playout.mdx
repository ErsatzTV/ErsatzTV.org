A playout file lists what a channel plays during one time window. The channel reads them from its playout folder
([`playout.folder`](./channel.mdx#playoutconfig) in `channel.json`) and loads the file that covers the current time.
Playouts are written by a scheduler, such as ErsatzTV (legacy).

- Every playout file must have `version`. See [Config Versions](./versions.md).
- Times are RFC 3339 with an offset, e.g. `2026-04-13T20:00:00.000-05:00`.
- For validation and completion in an editor such as VS Code, set `$schema` to the JSON schema,
  `https://ersatztv.org/schema/playout/0.0.6.json`. ErsatzTV Next ignores `$schema`.
- **Since** is the first playout version with the property. A property marked *unreleased* is on `main` and not in a
  release yet.

```json
{
  "version": "https://ersatztv.org/playout/version/0.0.6",
  "items": [
    {
      "id": "1",
      "start": "2026-04-13T20:00:00.000-05:00",
      "finish": "2026-04-13T20:30:00.000-05:00",
      "source": { "source_type": "local", "path": "/media/shows/episode-1.mkv" }
    }
  ]
}
```
