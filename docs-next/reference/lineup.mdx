The lineup is the file `ersatztv` runs: `ersatztv <lineup.json>`. It sets the HTTP server, where channels write their
HLS output, and which channels exist. `ersatztv add-lineup` creates one, and `ersatztv add-channel` adds channels to it.

- A relative path is relative to the lineup file.
- `version` is the format version of the file. See [Config Versions](./versions.md).
- For validation and completion in an editor such as VS Code, set `$schema` to the JSON schema,
  `https://ersatztv.org/schema/lineup/0.0.1.json`. ErsatzTV Next ignores `$schema`.
- **Since** is the first lineup version with the property. A property marked *unreleased* is on `main` and not in a
  release yet.

```json
{
  "version": "https://ersatztv.org/lineup/version/0.0.1",
  "output": { "folder": "./hls" },
  "channels": [
    { "number": "1", "name": "Channel 1", "config": "./channels/1/channel.json" }
  ]
}
```
